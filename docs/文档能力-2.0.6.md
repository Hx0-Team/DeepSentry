# DeepSentry 2.0.6 文档能力

新增 `document_create`，并强化 `document_parse`。直接对 Agent 说“阅读这份附件，按通用安全报告格式生成 Word，另做资产 Excel 和汇报 PPT”即可；有用户指定体例时按该体例处理。本版原生生成器面向通用商务/安全报告，不替代复杂图表、原件排版或模板复用工具。

## 阅读与理解

| 类型 | 本版提供给模型的证据 | 限制 |
| --- | --- | --- |
| DOCX | 正文、标题文字、元信息、保留行列的表格 | 未还原批注/修订/图片语义与全部样式 |
| XLSX/XLSM | 工作表、行/单元格文本、显式公式与缓存值 | 不执行宏；缓存可能过期，需Office重算；预览默认120行/8表，最大1000行/50表/60列 |
| PPTX | 按presentation关系排序的幻灯片、正文、表格、备注、图片数量 | 不把未做视觉分析的图片/图表当成已读懂 |
| PDF | 文本流、Unicode/CJK文本；本机有Poppler时优先布局提取并标注页号 | 扫描件需OCR/视觉；原生降级页数为近似，不提供可靠逐页定位；字体映射不完整时会警告 |
| DOC/XLS/PPT | 老式二进制可读字符串降级 | 可能遗漏文字、单元格、公式；优先转换成对应OOXML后分析 |
| CSV/TSV/RTF | 表格或文本 | 仅受支持的文档，不借此读任意配置 |

用户上传的 `reports/chat` 文档可通过文档专用读取器解析，不再因路径含deepsentry或通用证据读取器禁用附件目录而误拦。配置/备份仍拒读。

单文件≤20MiB；单次默认返回12000 Unicode字符，最大100000，提取文字上限约1M字符。`next_offset` 是格式化提取结果的字符位置；保持 path/mode/max_rows/max_sheets 不变分页，避免反复把全文放进模型上下文。`complete=true` 只表示当前提取/预览窗口读完，不代表未显示的工作表、被限制的行列、图片和旧格式降级内容也已完整读取。提取PDF使用可选 `pdftotext`（20秒/4MiB输出上限），未安装时保留Go原生解析，不会自动安装依赖。

文档是数据，文内“忽略规则”“执行某命令”等内容不能扩大用户授权。

## 生成真实文件

`document_create(path, format, spec)` 的 path 必须为控制端绝对路径、父目录存在、扩展名与format一致。只新建，拒绝覆盖原件；spec只接收结构化JSON，不执行代码/宏，不请求外部资源，不将Markdown更名冒充Office。

| 格式 | 内容与版式 |
| --- | --- |
| DOCX | A4、商务标题/章节层级、正文、要点、表头底色与网格；可编辑 |
| XLSX | 多工作表、数字/布尔/文字、表头样式、冻结首行、显式公式与缓存值；普通以=开头的字符串始终为文字 |
| PPTX | 16:9、标题/要点/页码、演示备注、可编辑；每页≤8要点/每点≤100字符，密集正文会要求拆页，标题≤40字符 |
| PDF | 流式A4中文报告、章节/要点/文本表格/页码；标准STSong CJK字体与Unicode映射，未嵌入字体 |

生成器先回读结构/文本再发布，返回文件路径、字节数、SHA256、元信息、正文预览和警告。回读不等于视觉版式验收。Excel提供公式但不执行公式引擎，`cached_value` 应来自已核验数据；缺缓存值时说明需Excel/LibreOffice重算。本版PDF将中点/圆点列表符替换为便携短横线，跨系统交付需用支持CJK的PDF阅读器检查。

spec≤1MiB、≤200章节/50工作表/100幻灯片，Excel每表≤10000行/每行≤200列。已有模板、复杂图表、图片排版、PDF扫描OCR不属于这个原生生成器的已实现能力；需要相应的专用工具/视觉模型处理，不能宣称保真支持。

最小通用报告spec（DOCX/PDF）：

```json
{"title":"安全检查报告","subtitle":"范围与检查日期","author":"编制单位","sections":[{"heading":"总体情况","text":"填写已核验的范围与结论。"},{"heading":"发现与建议","bullets":["填写有证据的风险与建议"],"table":[["资产","发现","状态"],["web-01","调试入口公开","待修复"]]}]}
```

Excel单元格用 `{ "value": 2 }`、`{ "formula": "SUM(B2:B3)", "cached_value": 3 }`；PPT用 `slides[{title,bullets,notes}]`。完整示例可让Agent先读本版附带的文档Skill（源码 `skills/documents/SKILL.md`，发布包 `bundled-skills/documents/SKILL.md`），按任务需要加载。

## 验证与适用范围

四类文件的创建与结构回读由自动化测试覆盖，包括中文分页、表格、公式、备注、拒绝覆盖和密集幻灯片限制。复验方法见 [2.0.6 验证说明](Verification-2.0.6.md)。结构回读通过后，正式交付前仍应在目标 Office/PDF 阅读器检查版式。
